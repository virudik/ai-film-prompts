# Shadow pilot — takeover brief (НЕ КАНОН)

Решение владельца D1, 09.10.2026: пилот на 7 дней, **09.10–16.10.2026**.

- **Как принимать смену — не меняется.** Полное чтение по `NEW-CHAT-HANDOFF.md`: 7 инструкций → fresh master → живые статусы. Файлы этой папки не заменяют ни один шаг и не являются источником истины.
- **Что здесь лежит.**
  - `takeover-brief.md` / `.json` — производный навигатор: хеши источников, 15 инвариантов с якорями, индекс сцен, наборы чтения по задачам, триггеры полного чтения.
  - `current-checkpoint.md` — дословный текущий блок handoff плюс действующие разделы ниже пометки «история».
- **Как собирается.** Файлы строит `scripts/build_takeover_brief.py` в workflow `shadow-brief.yml`. Workflow запускается при изменении канонических зеркал и статуса и после каждой синхронизации master. Коммит делается только при изменении содержимого.
- **Как проверяется.** Claude раз в день записывает результат в `pilot-log.md`:
  - валидность brief и якорей;
  - сравнение с живыми источниками;
  - контрольные вопросы двум агентам — по brief и по полному канону.

  Итог 16.10 решает владелец (D7 — переходить или нет).
- **Удаление.** Если пилот остановлен, удаляются эта папка, скрипт и workflow. Больше ничего не затронуто.

Проект и критерии: `AI-Film-Optimization-Design-2026-10-09.md` на Drive (папка AI Film Prompts Master), раздел 5.
