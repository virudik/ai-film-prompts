# Как пользоваться проектом AI Film Prompts

Короткая памятка для владельца проекта. Если через месяц всё забудется — начни отсюда.

## Главное правило

**Главный источник истины — Google Drive → папка `AI Film Prompts Master` → файл `video-prompts.md`.**

Не носи мастер-файл вручную между чатами, если у ИИ есть доступ к этой папке или публичному GitHub-зеркалу.

## Где что лежит

### Google Drive — главный рабочий источник
Папка: `AI Film Prompts Master`

В ней:
- `AI-PROJECT-GUIDE.md` — правила для ИИ;
- `USER-GUIDE.md` — эта инструкция для тебя;
- `video-prompts.md` — единственный канонический мастер промтов;
- `video-prompts.html` — удобная версия для просмотра;
- `film-analysis.md` — компактная карта текущего фильма;
- `film-backlog.md` — задачи, зависимости и идеи;
- `Seregius_montazhny_razbor.html` — большой монтажно-сюжетный разбор;
- `EDIT_PLAN_V2.csv` — монтажный план;
- `PROGRESS.md` — контрольные точки Work.

### Notion
Страница `AI Video Prompts — Master Hub` — это навигационный хаб со ссылками и правилами. Не редактируй там отдельную копию мастер-промтов.

### GitHub
Репозиторий `virudik/ai-film-prompts` — публичное read-only зеркало для Claude, Gemini, DeepSeek, Grok и других ИИ.

### ChatGPT Library
Внутренняя рабочая/резервная копия для ChatGPT. Это не главный источник для Work.

## Что писать обычному ChatGPT

### Если хочешь изменить промт
Напиши примерно так:

`Измени сцену 15 в мастере: ...`

или:

`Добавь этот утверждённый промт в мастер.`

ChatGPT должен:
1. сначала открыть свежий `video-prompts.md` с Google Drive;
2. изменить только нужную сцену;
3. сохранить тот же мастер-файл;
4. синхронизировать ChatGPT Library и GitHub-зеркало;
5. не создавать `v2`, `final`, `copy`, `final-final`.

### Если ты сам вручную изменил файл на Google Drive
Напиши:

`Синхронизируй мастер с Google Drive.`

Тогда Drive-версия считается самой свежей и её нельзя затирать старой копией.

### Если Work изменил мастер
Напиши:

`Work обновил мастер. Синхронизируй зеркала.`

ChatGPT должен прочитать свежую Drive-версию и обновить Library + GitHub.

### Если запустил сцену в долгую/медленную генерацию
Сразу напиши ChatGPT:

`Сцена N запущена в медленную генерацию — пометь её, чтобы повторно не запускать.`

ChatGPT должен отметить её в верхнем статус-блоке и в оглавлении мастер-файла. Когда генерация завершилась или упала с ошибкой, напиши:

`Сцена N закончила генерацию: [готово / ошибка / нужен новый дубль]. Обнови статус.`

Так мастер одновременно служит защитой от случайного повторного запуска.

## Что писать Work

Work нужен, когда задача зависит от всего фильма, монтажного анализа, backlog, Notion или нескольких сцен сразу.

Короткая команда:

`Используй проектные файлы из папки AI Film Prompts Master на Google Drive. Перед работой прочитай AI-PROJECT-GUIDE.md, video-prompts.md, film-analysis.md и film-backlog.md.`

Если Work должен изменить мастер:

`Внеси изменения в канонический video-prompts.md на Google Drive. Сначала прочитай свежую версию. Не создавай копий файла.`

Не прикладывай старый `video-prompts.md`, если Drive доступен.

## Когда использовать Work, а когда обычный чат

**Обычный ChatGPT:**
- придумать или улучшить один промт;
- посмотреть референсы;
- поправить камеру, диалог, движение, стабильность персонажей;
- быстро обсудить конкретную сцену;
- внести утверждённое изменение в мастер.

**Work:**
- сверить несколько сцен с текущим фильмом;
- проверить сюжетные зависимости;
- сопоставить `film-analysis`, `film-backlog`, Notion и мастер;
- массово организовать проект;
- провести большой аудит.

Не запускай Work для мелкой правки одного предложения без необходимости.

## Что давать Claude / Gemini / DeepSeek / Grok

Всем им сначала давай публичную `AI-PROJECT-GUIDE.md` и конкретные референсы сцены. В инструкции у каждого теперь есть своя роль:
- **Claude** — редакторская связность, логика, структура и длинные промты;
- **Gemini** — независимая проверка промта и визуальных референсов;
- **DeepSeek** — технический аудит промта: противоречия, тайминг, камера, перегруз, reference priority, negative prompt;
- **Grok** — креативная/комедийная вторая оценка: панчлайны, deadpan, темп, энергия сцены и альтернативные ходы.

Стартовая фраза для любого из них:

`Открой AI-PROJECT-GUIDE.md и следуй роли, которая там прописана для тебя. Прочитай актуальный video-prompts.md. Работай в режиме review only. Хочу обсудить сцену N.`

Если вопрос зависит от внешности персонажей — обязательно приложи картинки-референсы именно этой сцены.

Внешние ИИ по умолчанию **не меняют мастер**, а только предлагают правки. Хорошую правку потом принеси в ChatGPT фразой:

`[Название ИИ] предлагает вот это изменение сцены N. Оцени и, если подходит, внеси в мастер.`


## Если ChatGPT временно недоступен — Claude как резерв

Для Claude есть отдельная аварийная инструкция `CLAUDE-TAKEOVER-RUNBOOK.md`. Она лежит в Google Drive, GitHub, Notion и ChatGPT Library.

Если ты хочешь временно назначить Claude основным редактором, напиши ему:

`ChatGPT сейчас недоступен. Ты временно основной редактор проекта. Сначала прочитай CLAUDE-TAKEOVER-RUNBOOK.md, затем SYNC-RUNBOOK.md, AI-PROJECT-GUIDE.md и свежий video-prompts.md на Google Drive. Работай по takeover-протоколу.`

Если в Claude подключён тот же Google Drive/Notion аккаунт, он сможет работать там с правами этого аккаунта. Для прямого изменения `index.html`/GitHub ему нужен GitHub connector с write-доступом в самом Claude. Без GitHub write он всё равно может менять канонический Drive-master, а содержимое сайта должно попасть в GitHub через Drive→GitHub sync.

Публичная инструкция: `https://raw.githubusercontent.com/virudik/ai-film-prompts/main/CLAUDE-TAKEOVER-RUNBOOK.md`.

## Если другой ИИ не видит Google Drive

Дай ему публичные ссылки из GitHub:
- инструкция проекта;
- raw `video-prompts.md`;
- при необходимости `film-analysis.md` и `film-backlog.md`.

Для простого совета по одному промту огромный 22-раздельный HTML обычно не нужен.

## Что нельзя забывать

- Канон промтов только один: `video-prompts.md` на Google Drive.
- HTML — только просмотрщик, вручную его не редактировать.
- Notion — хаб, а не параллельный мастер.
- GitHub — зеркало для чтения другими ИИ.
- Library — внутренняя копия ChatGPT.
- Перед каждой правкой сначала читать свежий Drive-мастер.
- Если несколько ИИ дают советы — читать могут все, писать мастер должен только один редактор за раз.

## Самые полезные короткие команды

- `Измени сцену N в мастере: ...`
- `Добавь это в мастер.`
- `Синхронизируй мастер с Google Drive.`
- `Work обновил мастер. Синхронизируй зеркала.`
- `Проверь сцену N с учётом film-analysis и film-backlog.`
- `Удали сцену N из активного мастера: ролик готов и больше не нужен.`

## Если всё совсем забылось

Открой папку `AI Film Prompts Master` на Google Drive и сначала прочитай:
1. `USER-GUIDE.md`;
2. `AI-PROJECT-GUIDE.md`;
3. `video-prompts.md`.

Этого достаточно, чтобы восстановить весь рабочий процесс.


## Полная синхронизация проекта

Если хочешь, чтобы после правки я проверил **вообще всё**, напиши:

`Проведи полную синхронизацию мастера.`

Это означает, что ChatGPT должен не просто поменять локальный файл, а сверить и обновить:
- локальную рабочую копию;
- канонический Google Drive `video-prompts.md`;
- ChatGPT Library;
- GitHub raw mirror;
- публичный сайт GitHub Pages;
- Notion Hub.

После этого ChatGPT должен проверить публичную версию и только потом сообщить, что синхронизация завершена.

Техническая памятка для самого ChatGPT лежит рядом с мастером в файле `SYNC-RUNBOOK.md`. Если через месяц AI забыл архитектуру проекта, попроси его: `Сначала прочитай SYNC-RUNBOOK.md и AI-PROJECT-GUIDE.md, потом синхронизируй.`
