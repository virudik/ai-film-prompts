## Общее предупреждение о продукте (обязательно)

На всех трёх кадрах в центре — **явно generic featureless dark rectangular front-facing compositing proxy**: бесформенный тёмный прямоугольный силуэт «телефонной» пропорции **без** камер, выреза, кнопок, логотипов, UI и узнаваемой модели.  
Это **НЕ** изображение реального устройства HONOR и **НЕ** вымышленный «настоящий» HONOR-телефон. Подписи вне картинок должны говорить: концепт, продукт pending. Нельзя называть proxy «актуальным HONOR».

Запрещено в кадрах (и соблюдено): логотипы/типографика/числа/водяные знаки; claims по камере/AI/батарее/водозащите/лидерству/партнёрствам; UI и веб-мокапы; узнаваемые реальные модели устройств.

Формат всех кадров: **16:9**, **1280×720**, PNG (+ jpg preview-копии исходной генерации).  
Палитра кампании (ориентир): глубокий индиго / cyan–magenta neon / champagne-gold / coral.

## 1. `honor-realism.png` — фотореализм / live-action

**Предлагаемое имя шота:** «Неоновый орбитал / Suspended City Light»  
**Мотив:** ночной дождливый город; вокруг proxy зависают и кружатся ленты цветного неона (cyan / magenta / gold), будто свет города стянут в орбиту вокруг продукта. Люди — мягкий фон, боке, мокрый асфальт.  
**Механика wow:** suspended colored light ribbons (не «космические обои»).  
**Стиль:** photoreal cinematic, правдоподобные люди/город + VFX.  
**Промпт генерации:** см. `generation-prompts.json` → `honor-realism.png`.  
**Разрешение:** 1280×720 PNG.

**Выравнивание скрипта (предложение):** 20–30 с live-action ролик: открытие на мокрую улицу → появление proxy → захват уличного света в орбитальные ленты → финальный hold на крупном силуэте. Без копи про specs.

## 2. `honor-3d.png` — premium 3D

**Предлагаемое имя шота:** «Скульптурная сцена / Material Assembly Stage»  
**Мотив:** студийный CG-void; ленты brushed gold, frosted pearl/glass собираются в скульптурную сцену вокруг крупного matte-black proxy; тонкие орбитальные кольца.  
**Механика wow:** физический поток материалов, собирающихся в stage (не абстрактный космос).  
**Стиль:** чистый premium 3D CGI, sculptural — не фото и не 2D.  
**Промпт генерации:** `generation-prompts.json` → `honor-3d.png`.  
**Разрешение:** 1280×720 PNG.

**Выравнивание скрипта:** 20–30 с CG-ролик: материалы втекают → собирают stage → reveal proxy → slow orbit. Hero product space для поздней подстановки модели.

---

## 3. `honor-drawn.png` — рисовка / 2D

**Предлагаемое имя шота:** «Штрих, расцветающий в мир / Stroke Bloom World»  
**Мотив:** true 2D ink/paint на indigo paper; золотой контур proxy; волна/мазок слева и расцветающий иллюстрированный мини-мир (крыши, фонари, птицы, цветы) справа — живой скетч вокруг силуэта.  
**Механика wow:** линия/мазок → blooming illustrated world (цель промпта: continuous stroke; в результате сильная 2D-иллюстрация с волной+миром, стилистически однозначно drawn).  
**Стиль:** ink/watercolor/gouache illustration — не photoreal и не 3D.  
**Промпт генерации:** `generation-prompts.json` → `honor-drawn.png`.  
**Разрешение:** 1280×720 PNG.

**Выравнивание скрипта:** 20–30 с 2D motion: линия растёт → обвивает силуэт → мир расцветает → hold. Подходит как «drawn treatment» в тройном питче.
