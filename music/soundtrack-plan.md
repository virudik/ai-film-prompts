## Подход

Не отдельная случайная композиция на каждый 15–30-секундный ролик, а общая музыкальная логика. Один музыкальный эпизод может идти через несколько монтажных склеек. Для каждой сцены принимается решение: новый фон, продолжение предыдущего, сохранение встроенной музыки или тишина. «Охват всех сцен» не означает непрерывную музыку.

Исходная палитра: симфонический приключенческий оркестр, валторны и трубы, подвижные струнные, выразительные деревянные духовые, литавры; отдельные космические тембры. Собственные короткие мотивы и юмор, серьёзная подача нелепых событий. Не использовать узнаваемые мелодии Star Wars, Imperial March или игровые темы Warcraft. Общая эстетика — ориентир, не задание воспроизвести конкретную партитуру.

Предлагаемые семейства тем:
1. **Серёга:** уверенная короткая тема; героическая, тревожная и домашняя версии одного выбранного аудиомотива.
2. **Карта / древний ПК:** загадка, редкие ноты, постепенное раскрытие; разрешение при находке.
3. **Коты / РосКОТмос:** серьёзный низкий оркестр с сухим, едва заметным комическим оттенком; переход в игровую фактуру на красной точке.
4. **Путь / перелёты:** ощущение движения и открытия, вариации темы Серёги.
5. **Бытовая комедия / ремонт:** камерные дерево и пиццикато, паузы важнее постоянных акцентов.
6. **Ландшафты:** Татуин — сухая фактура, Набу — вода и воздух, Кашиик — дерево и глубина; единая оркестровая основа.
7. **Бой / погоня:** ритм и развитие, без необходимости подчёркивать каждый удар; снижение плотности под реплики.
8. **Дом / Warcraft:** облегчение и камерная версия темы героя, затем короткий собственный игровой пульс; бытовой финал в тишине.

Это предлагаемые семейства, не восемь уже записанных мелодий. Одинаковый текст промпта не гарантирует повтор одной темы. После выбора базового аудио использовать его фрагменты и развитие; если выбран инструмент продолжения/референса, сначала проверить на одном тесте сохранность мелодии и условия доступа.

## Конфликт со звуком роликов

Сначала отмечаем у каждого выбранного клипа: диалог, эффекты/атмосфера, музыка; доступны ли они отдельными дорожками. Сейчас этот аудит НЕ проведён. По наличию музыки в промпте нельзя надёжно определить результат.

| Исходный звук | Решение |
|---|---|
| Речь и эффекты без музыки | Добавить фон отдельно, опускать его на репликах и значимых шумах. |
| Хорошая встроенная музыка | Оставить, либо продолжить её монтажным переходом; второй фон поверх не класть. |
| Музыка без нужной речи/эффектов | Отключить исходный микс, восстановить нужную атмосферу/эффекты, добавить новый фон. |
| Речь, эффекты и ненужная музыка в одном миксе | Сначала пробное разделение на фрагменте; проверить речь, дыхание, хвосты и звуковые эффекты. |
| После разделения появляются артефакты | Оставить исходный звук или восстановить речь/эффекты отдельно; не объявлять дорожку очищенной. |
| Песня, танец, музыкальная шутка | Одна выбранная музыка, без дополнительного оркестрового фона. |
| Панчлайн / важная пауза | Увести музыку заранее, оставить реплику и реакцию без заглушающего акцента. |

Простое уменьшение громкости общего микса уменьшает и речь, и эффекты. Эквалайзер не отделяет музыку от речи. Разделение «вокал/инструментал» не равно полноценному отделению диалога, музыки и киношных шумов. Нельзя гарантировать чистое разделение.

На монтаже держать отдельные дорожки: **диалоги, атмосферы/эффекты, музыка**. В CapCut возможна ручная автоматизация громкости ключевыми точками. Сложную очистку и тонкое сведение удобнее делать в аудиоредакторе/DAW либо Fairlight/Premiere/Audition по наличию инструментов. Числа громкости задавать после проверки реального материала, не универсальными процентами.

## Процесс

1. Взять актуальный экспорт фильма с полным звуком либо монтаж с раздельными дорожками. Сверить выбранные новые сцены и порядок. Не считать старый58:48-хронометраж текущим.
2. Проставить вход/выход музыки, реплики, паузы, существующие песни. Для каждого cue заполнить audio_status, точный диапазон и решение.
3. Сделать три пилота: перелёт52/53, ремонт43–44, храм34/35/38. Предложенные задания в soundtrack-pilot-prompts.md. Сначала получить характер, затем проверять под картинкой.
4. Выбрать тембр и один мотив героя. Для пилотов достаточно одной генерации каждого задания с обычным числом вариантов сервиса, без бесконечного перебора.
5. Только после прослушивания и проверки под монтажом планировать полный объём. Рабочая оценка: 6–8 базовых музыкальных идей и около15–25 музыкальных эпизодов/редакций; это не число гарантированно необходимых генераций. Связанные сцены объединяются, часть остаётся без нового фона.
6. Генерировать материал с монтажным запасом: короткие вступления, ясные фразы, редактируемая середина, чистое окончание. При необходимости90–120секунд могут покрывать несколько соседних клипов. Точная длительность — по монтажу.
7. Резать, продлевать и сводить уже под картинку. Suno не гарантирует музыкальный акцент в конкретном кадре только по секундам в промпте.
8. Проверить весь фильм по звуку: разборчивость реплик, переходы, повторяемость тем, отсутствие двойной музыки, тишина перед сценой55. Проверка на наушниках и обычном динамике.
