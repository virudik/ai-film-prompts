## Статусы и правила ведения

| Статус | Значение |
|---|---|
| УЖЕ ЕСТЬ В ФИЛЬМЕ | Подтверждена указанная функция/сцена; это не гарантия совпадения с каждым словом старого сценария |
| РЕАЛИЗОВАНО ЧАСТИЧНО | Есть часть замысла, но недостаёт названного результата/связки |
| НУЖНА ДОРАБОТКА | Материал или готовый текст существует, требуется конкретное изменение |
| НУЖЕН НОВЫЙ РОЛИК | Выбранная сцена предполагает новую генерацию; подтверждённого подходящего готового дубля нет |
| НУЖЕН ПЕРЕХОД | Нужно связать существующие блоки; новый ролик необязателен |
| НУЖЕН ДИАЛОГ | Нужно определить/записать реплики, чтобы закрыть смысловой пробел |
| ВОЗМОЖНО УДАЛИТЬ | Кандидат на сокращение; удаление не согласовано и не выполнено |
| НУЖНА РУЧНАЯ ПРОВЕРКА | Решение зависит от исходного воспроизведения, точного дубля или авторского подтверждения |
| ОТЛОЖЕНО | Не находится в активной разработке; перенос из Notion не является одобрением |

В строках ниже **факт**, **решение**, **рекомендация** и **проверка** означают тип основания, а статус — состояние задачи. При изменениях обновлять существующий ID; не плодить альтернативные мастер-файлы. Готовый и больше не нужный промт удалять после подтверждения конкретного результата. Удалённые/старые идеи учитывать здесь, а не складировать в `video-prompts.md`.
