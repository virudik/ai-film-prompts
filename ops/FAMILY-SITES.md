## рудик.рф — устройство и правила правки

- 12 копий `index.html` в кириллических папках (`алина/`, `видео/`, `виталик/`, `иишница/`, `маша/`, `мои-видео/`, `обо-мне/`, `промты/`, `работа/`, `фото/` и т. д.) плюс корневой `index.html` и `404.html` должны оставаться согласованными: правка меню, плитки или блока делается во **всех** копиях.
- Общие файлы: `css/7.css`, `css/common.css`, `css/extra.css`, `js/loops.js`, `js/videos-data.js`, зацикленные видео `video/loops/*.mp4` (+ `.jpg` превью).
- Оригиналы не удаляются: прежние версии лежат рядом с суффиксом `-old`, исходные файлы владельца — `*-original.*`; при замене ролика старый переименовать, не стирать.
- **Кэш:** при любой правке CSS, JS или видео поднять параметр `?v=` у подключения этого файла во всех копиях страниц (иначе планшеты и телефоны держат старое; так был пойман съехавший CSS на планшете).
- `js/videos-data.js` — список «Мои видео»; запись `{title, rutube, file, poster}`. Ролик, которого ещё нет, — заглушка с пометкой «скоро». Свой mp4 в репозитории (`file`/`poster`) — временно; цель — Rutube (`rutube` = длинный код из ссылки `rutube.ru/video/<ID>/`).
- Тестовая версия (адаптивная вёрстка, тёмная тема и т. п.) — отдельная копия `/test/` с `noindex`, основной сайт не меняет; владелец сам решает, делать ли её основной.

## DNS и хостинг (reg.ru)

- Зоны обоих доменов — в reg.ru. Для `@`: четыре A-записи GitHub Pages `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; `www` — CNAME на `virudik.github.io`.
- Откат для обоих доменов: A-запись `31.31.198.146` (прежний конструктор reg.ru).
- `rudik.su` — переадресация сервисом reg.ru на рудик.рф (после выпуска HTTPS — на `https://`).
- Старый конструктор reg.ru остаётся запасным вариантом. **Кнопку «Опубликовать» там не нажимать никогда** — мусорные правки конструктора не публиковать.
- Отключение платных служб reg.ru — только по команде владельца; автопродление включено у нужных, у ненужных выключено.

## Правила

- Ничего на живых сайтах не меняется без «да» владельца. Не ломать рудик.рф: трогать только то, о чём просили.
- Токен GitHub не управляет настройками Pages и репозиториями (403). Включение Pages, домен и «Enforce HTTPS» (Settings → Pages) делает браузер на компьютере бота, вошедший как `virudik`.
- HTTPS — собственный сертификат GitHub; выпуск после смены DNS может занять часы. До выпуска переадресацию `rudik.su` на https не переключать.
- Токен нигде не печатать и не записывать.
