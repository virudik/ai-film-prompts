# Один Create на пункт

Статус: действует. Проверено: 16.11.2026.

Правило владельца: один Create на пункт, никаких автоповторов. Единственное исключение — явно поручённая владельцем техническая переделка под новым item id с суффиксом `-R2`. Неизвестный исход не повторять: только сверка. Только бесплатный Unlimited за 0 кредитов.

Прежняя политика «до двух технических повторов» (30.10 и разрешение для Grok 01.11) снята. Дословный текст — `archive/ops/wake-roles-until-2026-11-15.md`.

Живое поле `retry_policy` в `ops/topview-launch-queue.json` этим файлом не переписано: его меняют только отдельным compare-and-swap. Пока поле хранит старый бюджет, исполнители всё равно следуют правилу выше и автоповтор не делают.
