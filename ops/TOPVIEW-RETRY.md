# Повторы после подтверждённой ошибки

Статус: действует. Проверено: 16.11.2026.

Решение владельца 16.11.2026 (t634s3201). Это единственное место правила повторов. Остальные инструкции только ссылаются сюда.

- Неоднозначную или неизвестную отправку не повторять никогда: только сверка.
- После подтверждённой ошибки Topview можно повторить до двух раз, как в живом `retry_policy` очереди (`ops/topview-launch-queue.json`, не больше двух дополнительных попыток на пункт).
- Один Create на попытку.
- Перед повтором — тот же claim, intent и verify-before-create (`ops/LAUNCHER-COORDINATION.md`; обёртка `scripts/launcher_entry.py`, `ops/LAUNCHER-ENTRY.md`).
- Только бесплатный Unlimited за 0 кредитов.
- Техническая переделка, которую владелец явно поручил новым item id с суффиксом `-R2`, — новый пункт, не повтор той же попытки.

Живое поле `retry_policy` этим файлом не переписывалось.
